# Entrance-Desktop Notes

## Repository Layout
- `Entrance/`: backend submodule. Keep this folder name exactly as `Entrance`.
- `Desktop/`: Electron desktop source code.
- `Share/Linux/`: Linux desktop icons and `.desktop` files.
- `Share/Windows/`: Windows icons and shortcut assets.

## Startup Model
- The desktop app does not launch through `Entrance/start.sh`.
- Development startup: root `npm start` runs `Desktop/launch-electron.js`, then Electron loads `Desktop/main.js`.
- Linux packaged startup: the packaged executable starts Electron through the wrapper generated by `Desktop/scripts/after-pack.js`. That wrapper adds `--no-sandbox` and Wayland/X11 flags before executing the real binary.
- macOS packaged startup: the `.app` bundle starts Electron directly with `Desktop/main.js`.
- Windows packaged startup: the portable `.exe` starts Electron directly with `Desktop/main.js`.
- Backend startup is managed by `Desktop/main.js`, which forks `Entrance/server.js` and supplies the desktop backend environment.

`Entrance/start.sh` is only for running the backend submodule independently.
