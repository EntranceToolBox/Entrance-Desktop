**Repository Layout Plan**
1. Use `https://github.com/fcanlnony/Entrance` as a git submodule.
2. Clone the backend as a submodule and keep the folder name exactly `Entrance` (do not rename it).
3. Create a top-level folder named `Desktop` and place all GUI-related source code inside it.
4. Create a top-level folder named `Share`.
5. Use `Share/Linux` for desktop icons and `.desktop` files.
6. Use `Share/Windows` for desktop icons and Windows shortcuts/assets.

## Startup Model
- Do not treat `Entrance/start.sh` as the desktop app launcher.
- Development startup goes through root `npm start`, then `Desktop/launch-electron.js`, then Electron loads `Desktop/main.js`.
- Packaged Linux startup uses the Electron binary plus the wrapper generated by `Desktop/scripts/after-pack.js`; the wrapper handles `--no-sandbox` and Wayland/X11 flags.
- Packaged macOS startup uses the `.app` bundle and Electron loads `Desktop/main.js` directly.
- Packaged Windows startup uses the portable `.exe` and Electron loads `Desktop/main.js` directly.
- The desktop process starts the backend by forking `Entrance/server.js` from `Desktop/main.js`.
- `Entrance/start.sh` is only for running the backend submodule independently.
